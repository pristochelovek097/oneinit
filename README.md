OneInit
===========

```text                                          
8"    88             e8"       "8 
8      8           e8"          8 
8      8         e8"            8 
8      8         "8e            8 
8     8888         "8e          8 
8e    8888           "8e       e8 
```    

инициализационная система для дистрибутива COMBINE (преемник wilix).
Адаптированная версия: брендинг COMBINE, нативный менеджер сервисов
(S##/D##/K## + <name>.levels), runlevel 5 и автозапуск графики.
Можно портировать на другие дистрибутивы, если постараться.

===========

сборка
```bash
gcc -static -O2 -o init init.c
```
===========

утилиты (симлинки на тот же бинарник)

```bash
telinit 3          # консоль
telinit 5          # графика
in-status          # статус init и сервисов
in-service list    # список сервисов
in-service stop x11
in-service start x11
in-service restart x11
```

лицензия gpl-3.0, инит предназначен для дистрибутива COMBINE
